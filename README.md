## 실행 방법

```bash
bash run.sh
# → http://127.0.0.1:5001 접속
```

- Python 3.10+ 필요. 의존성은 `flask` 하나뿐이며 `run.sh`가 자동 설치합니다.
- 첫 실행 시 `sample_docs/`의 샘플 문서 5개가 자동으로 등록됩니다.

## 5분 시연 시나리오

| 시간 | 내용 |
|---|---|
| 0:00–0:30 | 첫 화면: 왼쪽에 등록된 문서 5개(사내 규정 4종 + 제품 매뉴얼 1종), 오른쪽 환영 카드와 추천 질문 칩 |
| 0:30–1:30 | 추천 질문 클릭 → "연차는 1년에 며칠 쓸 수 있어?" 답변과 함께 **📄 문서 2 · 02_휴가규정.md · 1번째 조각, 유사도 점수**, 노란 **하이라이트** 표시 확인 |
| 1:30–2:30 | "＋ 문서 업로드" → txt/md 여러 개 드래그 → 즉시 청킹·인덱싱, 문서 목록과 청크 수 갱신 확인 |
| 2:30–3:30 | 방금 올린 문서 내용으로 질문 → 새 문서에서 근거를 찾아 답변하는 것 확인 |
| 3:30–4:15 | 문서에 없는 질문("양자컴퓨터 큐비트 오류율은?") → **"문서에서 찾을 수 없습니다"** 라고 정직하게 답변하는 것 확인 |
| 4:15–5:00 | 잘못된 파일(.exe)·빈 파일 업로드 시 안내 메시지, 모바일 화면(반응형) 확인, 마무리 |

## 기술 스택

- **Backend**: Python 3 + Flask (단일 `app.py`, 약 400줄)
- **Storage**: SQLite (`chatbot.db`) — 문서·청크 저장
- **검색**: 자체 구현 TF-IDF + 코사인 유사도 (외부 라이브러리 불필요)
  - 한국어 조사·어미 대응: 단어 + 전체 부분문자열 토큰화
  - 유사도 임계값(0.06) 미만이면 "찾을 수 없음"으로 정직하게 응답
- **답변**: 발췌(extractive) 기반 — 상위 청크에서 질문과 겹치는 문장을 골라 출처와 함께 제시
- **Frontend**: 바닐라 HTML/CSS/JS (CDN 없음, 오프라인 동작), 반응형(모바일 사이드바 토글)

## 검증 내역

E2E 테스트(업로드→인덱싱→질문→답변+출처) 전부 통과:
업로드 성공/실패(.exe·빈 파일 거부), 알려진 질문 답변+출처+하이라이트,
새 문서 즉시 검색 반영, 문서 외 질문 정직 응답, 빈 질문 400 처리.

## 정식 구축 시 확장 방안

1. **LLM 연동**: 검색된 근거 청크를 컨텍스트로 GPT/Claude 등에 전달해 자연어 답변 생성
   (프롬프트에 "근거 밖의 내용은 답하지 말 것" 지시 + 출처 강제 표기)
2. **임베딩 검색**: TF-IDF → 한국어 임베딩 모델(e.g. multilingual-e5) + 벡터 DB(Qdrant/pgvector)로 교체해 의미 기반 검색
3. **문서 형식 확장**: PDF/DOCX/HWP 파서, OCR(이미지 스캔 문서)
4. **운영 기능**: 사용자 인증·권한별 문서 접근 제어, 질문 로그·피드백 수집, 답변 평가 지표
5. **배포**: Gunicorn + Nginx, HTTPS, 정기 백업
